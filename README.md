# CodeAlpha Task 3: Data Visualization (Titanic)

## Dataset
Cleaned Titanic passenger dataset (titanic_clean.csv).

## Charts created
1. Survival rate by gender
2. Passenger class vs survival
3. Age distribution
4. Ticket fare by class
5. Age vs fare scatter plot
6. Passengers by embarkation port (pie chart)
7. Combined dashboard

## Key Insights
- Female passengers had a much higher survival rate than male passengers
- 1st class passengers survived more often than 3rd class
- Most passengers were aged 20 to 40
- 1st class fares were far higher and more spread out

## How to run
pip install pandas matplotlib seaborn
python visualize.py

## Tools
Python, Pandas, Matplotlib, Seaborn
